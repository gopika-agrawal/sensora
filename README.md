SENSORA

An AI-powered career growth platform built using Next.js, Clerk Authentication, Prisma, and NeonDB.

Overview

SENSORA is a full-stack AI-powered web application focused on helping users improve their professional journey through modern career tools such as resume assistance, AI utilities, interview preparation, and onboarding workflows.

This project is currently under active development.
